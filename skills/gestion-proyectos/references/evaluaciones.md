# Casos de evaluación del PM

Usar fixtures o lectura; no ejecutar cambios de prueba sobre proyectos reales.
Registrar petición, datos, resultado observado y evidencia. Esta tabla no implica que las
pruebas integradas se hayan ejecutado.

| Caso | Resultado esperado |
|---|---|
| Restricción de IP sin requerimiento aprobado | Implementación Bloqueada; no inventar solución ni horario. |
| Hijas ejecutadas y confirmadas; Excel pendiente de Ricardo | Hijas Hecho, padre En revisión, solicitud de evidencia y dependencia de cierre conservadas. |
| Grabación afecta una pieza, otras pueden avanzar | Bloqueo parcial; no bloquear todo el entregable. |
| Predecesora cancelada | No liberar sucesora automáticamente. |
| Dos hojas Hecho de tres activas, peso igual explícito | 66,7% operativo; aceptación se calcula por separado. |
| Sin hojas o sin ponderación acordada | No calculable; no inventar porcentaje global. |
| Sin capacidad ni esfuerzo | Sin base suficiente para proyectar. |
| Actualización autorizada | Preservar bitácora, relaciones y comunicación; releer el resultado. |
| Solo diagnóstico | No escribir en Notion. |
